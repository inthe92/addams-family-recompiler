GOMEZ DEBUG HUD v1.0 - Mod API v2 vertical demonstrator
Requires the mod-manager-v2 experimental frontend, not the published beta.
Install ZIP with F2 > Install Mod. Select Enable, then Back to return to play.
The text displays the actual completed-state player reference X/Y in NES screen
coordinates, room ID, game state and frame. Initial-room ordinary movement is
verified. Other player contexts say PLAYER UNAVAILABLE; no guesses are shown.
Disable or uninstall through F2. --no-mods loads no script or HUD.
The overlay freezes during pause and redraws without new Lua updates at 120 Hz.
No game graphics, ROM, native game code, memory writes or networking included.
