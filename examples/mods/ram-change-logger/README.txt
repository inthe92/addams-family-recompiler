RAM Change Logger v1.0
Requires Modding SDK v2 development frontend. F2 > Install > Enable > Back.
Observes canonical internal RAM captures, not every write or hardware registers.
No guessed game variable meanings; no game data or modifications included.
F2 > Disable removes all observers. --no-mods bypasses loading.
Logs stay in the user Mods directory. Changing Lua/range needs no native rebuild.
