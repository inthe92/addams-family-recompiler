# Own-image visual layers — implemented API2

Requires `graphics.layers`; optional labels require `ui.draw`. Declare one or two
unique image IDs and paths in mod.json:

```json
"permissions": ["graphics.layers", "ui.draw"],
"images": {"mansion": "assets/mansion.png"}
```

ZIP manifest retains all normal API2 identity/target/entry fields. This is a script
package, not a translation/profile file. PNGs must be author's own distributable
art. The full working example is `examples/mods/mansion-parallax-demo`; its original
procedural silhouette is generated by `tools/mods/make_phase5_examples.py`.

```lua
function on_update()
    local t = game.get_clocks().simulation_seconds
    graphics.layer("viewport", "mansion", 210, 180, 100, 50, -4, 180,
                   math.sin(t)*45, math.cos(t)*8, 0.4, 0.15)
end
```

Signature: space, declared image ID, x,y,w,h,z,opacity,camera_x,camera_y,parallax_x,
optional parallax_y (defaults to x factor). Coordinates are integers; x±320,
y±240, dimensions1..320/1..240, z−16..16, opacity0..255. Camera must be finite and
within±4096; factors0..1. Final position subtracts camera×factor with truncation
toward zero. One instance per image ID per callback,16 total commands including
UI,100,000 candidate pixels. Independent x/y factors are supported. Scaling is
nearest; out-of-canvas pixels are clipped.

## Loading, ownership and composition

Only exact lowercase declared `assets/<name>.png` files: RGBA8, noninterlaced,
1..128 pixels per axis, compressed file≤64KiB, decoded image≤64KiB, two images
≤128KiB. CRC, chunk ordering, critical chunks, zlib stream termination, filters,
exact decoded size and trailing bytes are validated. Duplicate image IDs/paths,
undeclared PNGs, traversal, symlinks and missing assets are rejected before Lua.
Installation/inspection never executes a script. PNG validation/decoding may repeat in the helper’s Enable/check/assets
transactions; owned VM pixels are loaded once, with no decoding during draw/update. C++ independently bounds received data.

Owned source textures are CPU-composited into immutable completed-capture planes;
GL uploads a changed plane once and reuses it for extra presentations. The
presenter's upload counter tests real invalidation. Disable/error removes commands
and CPU assets; empty planes delete GPU textures, and a new presenter starts with
empty caches. Resize/F11 changes destinations, not simulation. No file/network/
native pointer access is exposed.

Delivered modes are viewport foreground and bounded window overlay. Background
behind NES and entity-linked layers are NOT IMPLEMENTED. z orders within a plane;
window plane draws above viewport regardless of z. UI text/rectangles use z0.
Mod IDs and submission index deterministically break ties.

## Demonstration limit

Mansion Parallax Demo uses a **synthetic camera**, visibly labelled. It is optional
decoration over the opaque NES image and may cover part of the original HUD.
Ctrl+Alt+V hides/shows it. It is not original game scroll, world geometry, scenery
extension, translucency of original pixels or2.5D. Real semantic scroll, background
occlusion and entity association need separate verified scene snapshots.
